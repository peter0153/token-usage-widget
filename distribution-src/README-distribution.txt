내 AI 한도 - Windows

설치
1. ZIP 파일의 압축을 모두 풉니다.
2. 설치.cmd를 실행합니다.
3. 바탕화면의 ‘Codex 사용량 위젯’ 또는 시작 메뉴 ‘내 AI 한도’로 실행합니다.
설치는 현재 사용자 폴더에 진행하며 관리자 권한을 요구하지 않습니다.
이미 설치했다면 같은 방법으로 덮어쓸 수 있고 로그인·설정은 별도 보관합니다.
ZIP을 다운로드만 해서는 설치·실행되지 않습니다. 압축 안에서 바로 실행하지 말고 모두 풀어 주세요.
설치.cmd는 프로그램을 현재 사용자의 AppData\Local\Programs\TeacherCodexUsageWidget에 복사하고 바로가기를 만든 뒤 실행합니다.
설치가 끝나면 다운로드한 ZIP이나 압축을 푼 폴더가 없어도 바로가기로 사용할 수 있습니다.
압축 폴더의 CodexUsageWidget.exe를 직접 실행할 수도 있지만 자동 업데이트를 사용하려면 설치.cmd로 설치해 주세요.

사용
- + 계정 추가에서 Codex를 공식 브라우저로 연결하거나 이 PC의 Codex를 연결합니다.
- 계정은 개인·업무·공부 등 별칭으로 구분합니다. Claude는 서비스 예정입니다.
- 큰 창과 작업표시줄 미니바는 독립적으로 켜고 끌 수 있습니다.
- ×는 큰 창만 숨깁니다. 완전히 종료하려면 알림 영역 우클릭 → 앱 종료를 선택합니다.
- 기록은 선택 계정 기준입니다. 오늘 PC 집계는 참고값이며 다른 기기는 포함하지 않습니다.
- 큰 창은 미니바 또는 트레이 아이콘을 두 번 눌러 다시 엽니다.
- 미니바 왼쪽 가장자리를 끌어 너비를 바꾸고, 최근 기록은 5일/10일로 선택합니다.
- 설정에서 밝은 회청색 라이트 테마 또는 다크 테마를 선택합니다.

업데이트
- 설정/트레이에 업데이트 확인 버튼과 자동 알림 선택이 있습니다.
- GitHub Releases의 공개 배포 파일을 조회합니다. GitHub 로그인은 필요하지 않습니다.
- 새 버전의 제작자 서명과 파일 해시를 확인한 후 프로그램을 교체합니다.
- 새 버전 실행 확인에 실패하면 이전 파일로 복구합니다.
- 업데이트 중 전원이 꺼지거나 설치 도구가 종료되어도 바탕화면 바로가기로 다시 실행하면 이전 파일을 복구합니다.
- ‘게시된 새 버전이 없습니다’는 현재 버전 이후의 공식 배포가 없다는 뜻입니다.
